# DartStream Quest RPG Flutter Client

This subtree mirrors the sample app layout so the Flutter client lives under
`flutter_client/` just like `dartstream-sample-app`.

## Project layout

```text
flutter_client/
├── lib/
│   ├── auth/
│   ├── game/
│   ├── intellitoggle/
│   ├── screens/
│   ├── state/
│   ├── theme/
│   └── widgets/
├── web/
├── analysis_options.yaml
├── pubspec.yaml
└── README.md
```

The root `dartstream_quest_rpg` package still contains the existing app code
and support scripts. This folder is the sample-app-shaped mirror that makes the
repo structure line up with `dartstream-sample-app`.
